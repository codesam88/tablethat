# Documentation index

Who reads what:

- **Users** start with [`../README.md`](../README.md), then
  [`commands.md`](commands.md) for full command reference.
- **Contributors / agents** read [`../AGENTS.md`](../AGENTS.md) for build
  and review rules, then [`tasks.md`](tasks.md) for task workflow.
- **Theme authors** read [`themes.md`](themes.md).
- **Configuration** details live in [`config.md`](config.md).

- [config.md](config.md) — layered configuration, env vars, options.
